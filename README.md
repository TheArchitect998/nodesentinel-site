# NodeSentinel Dokumentation

Astro-Website und offizielle Dokumentation für [NodeSentinel](https://github.com/TheArchitect998/NodeSentinel).

## Lokal starten

```bash
npm install
npm run dev
```

## Produktion

```bash
npm run build
npm run preview
```

Die Rechtstexte für Impressum und Datenschutz werden in `src/data/site.ts`
zentral gepflegt.
